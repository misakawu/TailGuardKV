## Summary

当前状态：代码侧已有 `run_experiment.py`、Policy/Backend/Metric 基础接口、7 个 policy 注册入口，但 P1 口径仍不一致，P2 缺少包含 `tailguard` 与 `quality_oracle` 的可验收 smoke 表。

## Key Changes

- 统一 quality loss 主指标：把 `qa_long_context` 映射到 F1；每条 profile row 写入 `extra_primary_metric`，exact/full 行也写；summary 的 `primary_metric_distribution` 必须非空。
- 统一违例率口径：`MetricCollector.summarize_profiles()` 不再固定 `epsilon=0.5`；改为接受 `epsilons`，输出 `violation_rate_eps0p05`、`violation_rate_eps0p1` 等，与 `profile_summary.py` 和 policy summary 对齐。
- 隔离 dry-run：dry-run profile row 写入 `extra_dry_run=true`、`extra_source=synthetic_schema_check`、`extra_backend=synthetic`；dry-run summary 明确标记；measured replay 继续默认拒绝 dry-run。
- 文档与表字段区分 runtime/backend：profile 输出保留 `extra_backend`、summary 保留 `backend_distribution`；README 明确 Transformers/Qwen2 runtime 不是 vLLM/LMCache serving backend。
- 完整策略 smoke：`configs/pilot_50.yaml` 与 runner 输出必须覆盖 7 策略：5 baseline + `tailguard` + `quality_oracle`；summary 必须含 p95 TTFT、KV memory、quality loss、violation、fallback ratio、action distribution、controller 分项开销、oracle 标记。
- H0/H1/H2-lite 汇总检查：新增一个轻量验收汇总函数或 CLI 检查，基于已生成 summary 判定是否具备 tail-risk、coverage/fallback、收益对比字段；先报告 evidence，不强行宣称通过科学假设。
