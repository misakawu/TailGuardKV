# 会话级重构

本文只记录本次已经落地的 profile 层修改，不再保留原执行计划。

## 目标

本轮修改把 profile 相关链路从“只看单请求”推进到“可携带会话上下文的测量与回放”：

- adapter payload 改为传递 `Request.effective_prompt`
- profile/runtime payload 显式携带 `session_id`、`turn_index`、`history_turns`
- profile measurement、profile table、measured replay、policy summary 统一消费会话字段
- dry-run 与测试链路支持 `resident` / `evict` / `restore` / `recompute` 生命周期事件
